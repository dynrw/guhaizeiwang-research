## 核心修正（相对本仓库 2026-11-09 之前的版本）

1. **起始资金**：334,115.89（2016-02-21 持仓页：余额 37,676.89 + 市值 296,439.00）。旧值"29.64 万"是持仓市值。开帖前史（本人 2026-09-24 原话）：2016 年元旦熔断腰斩至约 50 万 → 取十几万老家买房 → 剩三十多万"重新启航"。
2. **2016/2017 不是亏损年**：剔除两年合计 15.15 万转出后，2016 ≈ +9%、2017 ≈ −2%（旧估 −18%/−31.6% 未剔流出）。与 2016-12-15 原话"算上转出去的钱 今天总算开始盈利了"互证。
3. **2019**：+38.3%（旧估 +61.6% 高估，因当年有 15 万转入）。上半年一度 +300%+（4 月末 97.1 万），随后回吐——对应"上半年接近四倍 最后只剩一点点"。
4. **2018**：重建 +57.4%，本人原话"大概 70%"偏高。
5. **叙事重写**：不是"连亏两年后逆袭"，而是**起步前熔断腰斩 → 两年横盘 → 2018 起连续八年正收益**。
6. **十年全记录**：33.4 万（2016-02）→ 4,156 万（2026-11-09），累计约 **124 倍**；期间净出金 506 万（含 2024-11-29 一次性 300 万"给姐姐们买房"），加回出金的总财富倍数约 **139 倍**。

## 曲线上的关键时刻（月末粒度）

- 2016-12：三江购物主升，单月 +54%
- 2019-02：东方通信周期，单月 +82.4%（38.9 万→71.0 万）
- 2024-10：九月底史诗行情冲上 **2,050 万** → 12 月回落 847 万，三个月 **−58.7%**（"像做了一场梦"）
- 2025-08~12：+98.5 万/月节奏冲至 2,131 万（年度 +151.69%）
- 2026-06：峰值 5,929 万（06-30 月末口径）→ 11 月回落至 4,156 万（**−29.9%**）
- 月末粒度最大回撤：**−58.7%**（2024-10 → 2024-12，已剔出金影响按 MD 口径）与 **−56.6%**（2016-02 → 2017-06，含出金的资产口径）
