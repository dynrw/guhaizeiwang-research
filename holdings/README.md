# 每日确认持仓

由 GLM 在每个交易日收盘后按 `DAILY_RUN.md` 写入，文件名为日期。

## 用交割单还原打码个股（reconstructed_positions.csv）

2026-06-18 起持仓截图里的个股被作者打码，但他每周会发一次交割单。做法：

1. 以 2026-06-17 收盘未打码的持仓截图为基线（[楼层](https://www.tgb.cn/a/1ykAFNDujlw/99904554#99904554)）。
2. 把 2026-06-18 至 2026-11-05 的 20 张交割单逐笔识别，按股票累加买卖股数，得到每只股票的净持股。逐笔明细和原图只放在私有仓库，本仓库只放算出来的持仓。
3. 对账：用当天收盘价乘净持股，和持仓截图的「总市值 − 新标准券」比较。07-31、09-30、10-16、11-05 四个日子都一分不差；11-05 截图打码 7 行（6 红 1 蓝），与还原出的 7 只个股及盈亏颜色一致。
4. 最近一张交割单之后（11-06 起）的买卖只能从持仓截图底部露出的「持仓 0」行推断，例如福莱新材、凡拓数创 11-09 清仓。之后新买的股票要等下一张交割单才能补上。

net_shares 是截至 last_trade_date 的净持股，不保证今天仍持有。
